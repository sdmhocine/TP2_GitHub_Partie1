# TP2 – GitHub Collaboration

## 📌 Description

This repository was created as part of a practical exercise (TP2) to learn and practice collaborative development using **Git and GitHub**.

The objective is to understand how multiple developers can work on the same project, share their contributions, and manage changes using Git.

## 🎯 Objectives

- Understand Git and GitHub fundamentals.
- Clone an existing remote repository.
- Make and commit local changes.
- Push contributions to a shared repository.
- Synchronize local and remote repositories using `git pull`.
- Understand how to use `git pull --rebase`.
- Practice collaborative work and version control.

## 🛠️ Technologies Used

- Git
- GitHub
- PowerShell

## 🚀 Git Commands Practiced

| Command | Description |
|---|---|
| `git clone` | Clone a remote repository |
| `git add .` | Stage modified files |
| `git commit -m "message"` | Save changes locally |
| `git pull origin main` | Retrieve and integrate remote changes |
| `git pull --rebase origin main` | Retrieve changes and replay local commits |
| `git push origin main` | Upload local commits to GitHub |
| `git remote -v` | Display remote repositories |

## 📖 Conclusion

This practical exercise demonstrates the importance of version control in collaborative software development. Git and GitHub allow developers to track modifications, synchronize their work, and collaborate efficiently on shared projects.
